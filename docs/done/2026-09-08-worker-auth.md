# Worker 私有状态鉴权与双仓核对（2026-09-08）

## 已完成

- `worker.mjs` 为 `GET /status`、`POST /talk`、`POST /interpret`、`POST /broadcast` 加入 `Authorization: Bearer <OWNER_TOKEN>` 鉴权。
- 无非空 seed/layer 的 `GET /coin` 会读取 SOUL，因此同样要求密钥；公开编号、词形及 seed/layer 造词保持可用。
- 缺失或空白配置返回 503；错误、缺失或格式不合法的授权返回 401。拒绝请求不读写 KV，错误信息不包含请求密钥或私有状态。
- 响应禁止缓存，跨域预检允许 `Authorization`；平台定时任务继续按原逻辑运行。
- README、项目指南和部署模板说明密钥配置、接口分界、升级顺序与实际版本关系。

## 验证

- `npm test`：32 项通过（包含新增私有接口拒绝、无副作用、公开访问、授权别名和定时任务回归）。
- `python3 -m unittest discover -s tests -v`：9 项通过。
- 现有同步脚本对新版引擎采样 1544 个编号、83 个词族、14612 条编号表均一致。但脚本不检查完整导出 API，它输出的“双仓完全同步”不能作为版本等价证明。

JS 包 1.2.0、Python 包 4.1.0。新版增加汉译反查、语义检索、按义造词、双实现造词对等及更多测试。
